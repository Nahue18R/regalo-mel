# 🎮 Regalo interactivo para la po

Un juego 2D pixel art interactivo hecho con amor. Nahuel llega con la YBR 125, le entrega un ramo a Mel, y ella abre la carta con Snoopy.

## 🚀 Cómo funciona

1. **Intro**: Mel espera esperando en frente de la droguería (Carlos Gardel 3546, Avellaneda)
2. **Llegada**: Haces click y Nahuel llega con su YBR 125 negra
3. **Regalo**: Se baja, camina hacia Mel y le entrega el ramo
4. **Carta**: Aparece la carta con el Snoopy dibujado por Nahu
5. **Abrir**: Haces click y se abre la carta con el mensaje
6. **Final**: Confeti, estrellas, y el mensaje "Tkm, Nahu 💛"

## 📁 Archivos

- `index.html` - Estructura del juego
- `style.css` - Estilos
- `script.js` - Lógica e interactividad (todo el pixel art se dibuja en canvas)
- `README.md` - Este archivo

## 🎨 Características

- ✅ Pixel art en canvas (sin imágenes externas)
- ✅ Animaciones suaves
- ✅ Interactividad 100%
- ✅ Responsive (funciona en mobile y desktop)
- ✅ Graffiti con la frase personalizada
- ✅ Snoopy con flor (pixel art)
- ✅ YBR 125 y Honda GLH 150 en pixel
- ✅ Confeti al final

## 📱 Cómo probar localmente

```bash
# Clona el repo
git clone https://github.com/Nahue18R/regalo-mel.git
cd regalo-mel

# Abre en el navegador (o sirve con live server)
open index.html
# o
python -m http.server 8000
# y ve a http://localhost:8000
```

## 🚀 Desplegar en Netlify

1. Sube el repo a GitHub
2. Ve a [Netlify](https://netlify.com)
3. Conecta tu repo
4. Deploy automático ✨
5. Genera el QR del link
